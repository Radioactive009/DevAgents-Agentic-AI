Messaging Architecture Comparison: Blackboard vs. EventBus (Req 1)

Empirical benchmark executed on 8 parallel workers with 1,200 events (compare_messaging.py):

Blackboard (Mandatory Core) Primary Arch
Sequential Latency (Avg):
305.23 µs
Throughput (8 workers):
17,116 events/sec

Why Must: Central thread-safe state store ensures immediate coherent state across self-repair iterations with zero serialization or event replay overhead.

EventBus (Pub/Sub) Comparative Arch
Sequential Latency (Avg):
85.45 µs
Throughput (8 workers):
43,671 events/sec

Characteristics: High decoupled throughput with append-only event stream, suitable for independent microservices, but requires event-sourcing reduction.

Evaluation Dimension Blackboard Architecture (Must) EventBus Architecture
State Centralization Strict single thread-safe source (RLock) Event-sourced projection reducer
Lock Contention Lock held during state tree updates Lock held only for event append
Self-Repair Suitability Optimal (Zero lag on test-debug-repair loop) Requires subscriber synchronization
