# Sub-problem Question it answers Solved by
1 Screen user prompt for threats Is the request safe, or trying prompt injection, jailbreaks, or malware? Security Guardian (PromptGuard)
2 Design system architecture What components, files, schemas, and acceptance criteria are needed? Software Architect (Google ADK)
3 Synchronize shared state How do agents share context without race conditions or memory corruption? State Coordinator (Blackboard)
4 Write modular source code How to implement clean, working code matching the architecture plan? Software Developer (CrewAI)
5 Verify syntax & design patterns Is syntax tree valid without executing code? What are API best practices? Static Inspector (MCP AST & SQLite)
6 Verify truth honestly Does it actually run and pass tests in reality, with zero AI hallucination? Test Sandbox (Subprocess Pytest)
7 Diagnose failures & self-repair Why did tests fail, and what minimal atomic patch fixes the root cause? Self-Healing Duo (Debugger & Repairer)
